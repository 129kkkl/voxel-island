# 空島禅寺 — Voxel Zen Temple

Three.js 实现的 3D 体素风格日式浮空岛寺院场景。浏览器打开即可环绕观赏。

## 运行

```bash
npm install
npm run dev
```

然后在浏览器中打开终端提示的地址（默认 http://localhost:5173 ）。

构建生产版本：

```bash
npm run build
npm run preview
```

## 操作

- 鼠标左键拖拽：旋转视角
- 滚轮：缩放
- 右键拖拽：平移
- 右下角按钮：开关自动旋转 / 樱花粒子

## 场景内容

| 建筑 | 说明 |
|------|------|
| 本堂 | 主殿，入母屋造歇山顶，中轴核心 |
| 三重塔 | 三层宝塔，金色塔刹，位于东侧 |
| 配殿（×2） | 左右对称，切妻造悬山顶 |
| 山门 | 八脚门，二层带唐破风 |
| 手水舍 | 参道旁，开放亭式水舍 |

景观：参道、枯山水、石灯笼、鸟居、樱花树、松树、池塘、云海、远山雾影、飘落樱花。

## 技术

- Three.js 0.160 + Vite 5
- 体素通过 `THREE.InstancedMesh` 按颜色分组渲染
- 晨昏方向光 + 半球光 + 雾效
- 粒子系统：樱花花瓣、云海
